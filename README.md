# wrisp-site

Wrisp 官网的源码。

> **今天，你需要一个创作分身。**
> 说话代替打字，整理交给 AI，数据永远留在你的机器。

Wrisp 是一款本地优先的个人创作 AI：Markdown 存在你自己的目录里，识别、整理、召回都能在本机跑完，要用云端模型就接你自己的 Key。应用本身作为闭源免费软件单独分发，这个仓库只有站点。

## 线上地址

<https://liqms.github.io/wrisp-site/>

## 目录

```
index.html      整站单页（样式与脚本内联，无构建步骤、无第三方运行时依赖）
assets/         图标与社交分享卡片（og-zh.png / og-en.png，1200×630）
```

## 本地预览

没有构建步骤，起一个静态服务器即可：

```bash
python -m http.server 8080
# 或：npx serve .
```

然后打开 <http://localhost:8080/>。直接用 `file://` 打开也能看，但分享卡片的相对路径与 `localStorage` 在 `file://` 下行为不同，建议走本地服务器。

## 语言

当前是一份页面、两种语言：右上角切换，或用 `?lang=zh` / `?lang=en` 直接寻址；选择会记住。没有已存选择时默认落在中文，也**不做浏览器语言嗅探**——同一个 URL 对不同的人返回不同内容，爬虫和分享链接都不可复现。

下一步会把两种语言拆成 `/`（英文）与 `/zh/`（中文）两份各自可被索引的静态页面，`hreflang` 互指、各出 `canonical`，并按访问地区选择默认语言。届时页内切换会变成链接跳转。

## 已知缺口

- **等待名单表单还没有后端。** 提交只在前端校验并给出提示，数据不会离开浏览器。接通入库与发信通道之前，请不要把它当作报名渠道。
- **`og:url` 与 `canonical` 仍是相对路径**，等国际域名定稿后一次性替换为绝对地址。
